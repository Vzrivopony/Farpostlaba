# Лаба с поднятием БД для логов
У генератора логов(generator.py) есть входные параметры --start-date 2025-04-01 --end-date 2025-04-07 для задания промежутка создания логов

У агрегатора такие входные параметры  --start 2025-04-01 --end 2025-04-30 --output forum_report.csv это начальная, конечая дата агрегации и название выходного файла

# Поднятие Jenkins
Дженкинс поднимается вместе с MySQL БДшкой из докер компоузера

После того, как контейнер запустится, нужно перейти по http://localhost:8080 и Задать админа и скачать следующие плагины:
     Git Plugin
     Pipeline Plugin
     Pipeline Utility Steps
     
Также нужно закинуть файл mysql-connector-j-9.3.0.jar(Есть в ветке) по этому пути /var/jenkins_home/war/WEB-INF/lib/

Можно использовать эту команду - docker cp mysql-connector-j-9.3.0.jar <Название контейнера с Дженкинсом>:/var/jenkins_home/war/WEB-INF/lib/

# Создание пайплайна
Нужно создать новый пайплайн и вставить в него скрипт pipeline.groovy и снять галочку с Use Groovy Sandbox.
Затем перейти по этому адресу http://localhost:8080/manage/scriptApproval/ и одобрить скрипт пайплайна
Поставить триггер на автовыполнение скрипта каждый день H H/24 * * *
Запустить вручную, если не хотим ждать день
